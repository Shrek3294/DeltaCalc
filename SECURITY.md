# Security Policy

## Supported Versions

DeltaCalc receives active security and compatibility fixes on the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.9.x   | :white_check_mark: |
| < 0.9.0 | :x:                |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in DeltaCalc, please do not disclose it publicly on the issue tracker.

Instead, please report security concerns directly via GitHub Private Vulnerability Reporting or by contacting the repository maintainers directly.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue or a proof-of-concept.
- Any suggested fixes or mitigations.

We will review reports promptly, acknowledge receipt within 48 hours, and work towards a security patch release.
